# Migration: 0.1.x → 0.2.0

> **Released:** 2026-07-13
> **Breaking:** Yes (config schema change)
> **Estimated upgrade time:** 15 minutes

## What's new in 0.2.0

- **Phase 2 ship**: agent loop with retry, loop detection, stall
  detection, JSON repair.
- **Multi-provider**: Anthropic, OpenAI, Gemini, Ollama, Mock.
- **TUI polish**: 35+ iterations, 20+ themes, screen-reader mode.
- **11-agent swarm**: Scout → Architect → Coder → Reviewer → Tester →
  ... → Documenter.
- **3-tier memory**: ephemeral / persistent JSONL / external vector.
- **SICA self-improvement loop**.
- **3053 tests passing, 0 regressions**.

## Breaking changes

### 1. Config schema

The `[provider]` section in `~/.goli/config.toml` is replaced by
`[model]`:

**Before (0.1.x):**

```toml
[provider]
default = "anthropic"
model = "claude-3-5-sonnet"
api_key = "${ANTHROPIC_API_KEY}"
```

**After (0.2.0):**

```toml
[model]
default = "anthropic/claude-3-5-sonnet"
```

API keys are now env vars only (`ANTHROPIC_API_KEY`,
`OPENAI_API_KEY`, etc.), not config keys. This is more secure
(no keys in config files that might be committed).

**Migration:**

```bash
# Convert your old config
goli migrate-config --from 0.1 --to 0.2

# Or manually: edit ~/.goli/config.toml and apply the change above.
```

### 2. Session format

Sessions stored in 0.1.x are **not compatible** with 0.2.0. The JSONL
schema changed (added `toolCallId`, `toolName`, `toolInput`,
`toolResult` fields).

**Migration:**

```bash
# Back up old sessions
mv ~/.goli/sessions ~/.goli/sessions.0.1

# Old sessions remain readable via:
goli sessions export --format markdown <old-session-id> --legacy 0.1
```

Old sessions are not auto-migrated. If you need them, export to
Markdown first, then start fresh.

### 3. CLI flags

| 0.1.x flag   | 0.2.0 flag                       |
| ------------ | -------------------------------- |
| `--provider` | `--model` (with provider prefix) |
| `--api-key`  | (env var only)                   |
| `--no-tui`   | `--headless-output text`         |
| `--json`     | `--headless-output json`         |

### 4. Slash commands

| 0.1.x              | 0.2.0                       |
| ------------------ | --------------------------- |
| `/provider <name>` | `/model <provider>/<model>` |
| `/clear`           | `/reset`                    |
| `/quit`            | `/exit`                     |

## Step-by-step upgrade

1. **Back up**:

   ```bash
   tar czf goli-backup-0.1-$(date +%F).tar.gz ~/.goli/
   ```

2. **Export any sessions you want to keep** (as Markdown):

   ```bash
   for id in $(goli sessions list --format csv | tail -n +2 | cut -d, -f1); do
     goli sessions export "$id" --format markdown > "session-$id.md"
   done
   ```

3. **Upgrade**:

   ```bash
   npm install -g goli-cli@0.2.0
   ```

4. **Migrate config**:

   ```bash
   goli migrate-config --from 0.1 --to 0.2
   # Or manually edit ~/.goli/config.toml per the breaking changes above.
   ```

5. **Verify**:

   ```bash
   goli doctor
   goli --version  # should print 0.2.0
   goli -p "hello" --headless-output json
   ```

6. **Set API keys as env vars** (if you had them in config):

   ```bash
   echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
   source ~/.zshrc
   ```

7. **Start the TUI**:
   ```bash
   goli wakeup
   ```

## Rollback

If 0.2.0 breaks something:

```bash
npm install -g goli-cli@0.1.5   # or your previous version
tar xzf goli-backup-0.1-*.tar.gz -C /
```
