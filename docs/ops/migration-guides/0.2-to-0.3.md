# Migration: 0.2.x → 0.3.0

> **Released:** 2026-07-25
> **Breaking:** No (additive — Goli Studio is opt-in)
> **Estimated upgrade time:** 5 minutes

## What's new in 0.3.0

- **Goli Studio (experimental)**: a Next.js 16 web console for the
  Goli-CLI agent. Opt-in; the CLI is unchanged.
- **Local-LLMs router**: PII gating + complexity routing for users
  who can't send all prompts to a cloud provider.
- **5 workspace packages** (was 3): added `vscode-ext` and `studio`
  to the npm workspaces.
- **New convenience scripts**: `studio:dev`, `studio:build`,
  `studio:runtime`, `studio:db:push`, `studio:db:generate`.
- **46 ADRs** (was 45): added ADR 0046 (real tree-sitter, supersedes
  ADR 0022).

## Breaking changes

**None.** 0.3.0 is fully backward-compatible with 0.2.x.

- The CLI behaves identically.
- The config schema is unchanged.
- The session format is unchanged.
- All CLI flags and slash commands work the same.

The only "change" is that the root `package.json` now lists
`packages/vscode-ext` and `packages/studio` as workspaces. If you
run `npm install` at the root, you'll get the Studio's dependencies
installed too (Prisma, Next.js, etc.). If you don't want this, you
can continue to use `packages/core` / `packages/cli` / `packages/evals`
as before — the new workspaces are additive.

## Step-by-step upgrade

1. **Upgrade**:

   ```bash
   npm install -g goli-cli@0.3.0
   # OR from source:
   git pull
   npm install
   npm run build
   ```

2. **Verify**:

   ```bash
   goli doctor
   goli --version  # should print 0.3.0
   goli -p "hello" --headless-output json
   ```

3. **(Optional) Try Goli Studio**:

   ```bash
   npm run studio:db:generate
   npm run studio:db:push
   npm run studio:runtime &  # in background
   npm run studio:dev
   # open http://localhost:3000
   ```

4. **(Optional) Try the local-LLMs router**:
   ```bash
   goli wakeup --local-llms --workspace ~/my-private-project
   ```

## What's deprecated

Nothing. No features are deprecated in 0.3.0.

## What's planned for removal in 1.0.0

- The `--no-tui` flag (use `--headless-output text` instead). It
  still works in 0.3.0 but emits a deprecation warning.
- The `[provider]` config section (use `[model]` instead). It still
  works in 0.3.0 but emits a deprecation warning.

Both will be removed in 1.0.0. Update your scripts and config now to
avoid surprises.

## Rolling back

If 0.3.0 breaks something (it shouldn't, but just in case):

```bash
npm install -g goli-cli@0.2.5   # or your previous version
# OR from source:
git checkout v0.2.5
npm install
npm run build
```

No data migration is needed for rollback — sessions and config are
unchanged.
