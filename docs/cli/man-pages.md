# Man Pages — Goli-CLI

> **Standard:** roff format (man(7)).
> **Tool:** generated from Markdown via `go-md2man` (planned).
> **Last updated:** 2026-07-25

This directory holds the **man pages** for Goli-CLI. Man pages are
intended for **power users** who want to look up a flag from the
terminal without leaving the keyboard.

The man pages are generated from the
[Command Reference](command-reference.md) by `scripts/gen-man-pages.ts`
(planned). The source Markdown is the single source of truth; do
not edit the `.1` / `.3` files directly.

## Installing

If you installed Goli-CLI via `npm install -g goli-cli`, the man
pages are installed automatically:

```bash
man goli              # the main page
man goli-wakeup       # the wakeup subcommand
man goli-config       # the config file format
```

If you installed from source:

```bash
npm run gen:man-pages
sudo cp man/*.1 /usr/local/share/man/man1/
sudo cp man/*.5 /usr/local/share/man/man5/
```

## Rendering

This file is the human-readable index. The actual man pages are
in `man/` (planned; generated by `scripts/gen-man-pages.ts` from
[command-reference.md](command-reference.md)).

The man pages use the
[man(7) roff format](https://man7.org/linux/man-pages/man/man/man.7.html).
They are generated with
[go-md2man](https://github.com/cpuguy83/go-md2man) (or
[mango](https://github.com/muesli/mango) for Go).

.TH GOLI 1 "2026-07-25" "goli-cli 0.3.0" "User Commands"
.SH NAME
goli \- enterprise-grade, open-weight-first AI coding agent
.SH SYNOPSIS
.B goli
[\fIglobal options\fR]
[\fIsubcommand\fR]
[\fIsubcommand options\fR]
[\fIargs\fR]
.SH DESCRIPTION
Goli-CLI is an enterprise-grade AI coding agent for the terminal.
It's a multi-agent swarm with multi-provider LLM support, a
kernel-enforced sandbox, deterministic hooks, a 3-tier memory
system with self-improvement (SICA), and first-class enterprise
compliance (SBOM gate, audit log, PII gating, EU AI Act posture).
.SH OPTIONS
.TP
.BR \-p ", " \-\-prompt " " \fItext\fR
Run headlessly with this prompt and exit.
.TP
.BR \-\-model " " \fIid\fR
Override the model for this session.
.TP
.BR \-\-mode " " \fIbuild|plan|god|local-llms\fR
App mode. Default: build.
.TP
.BR \-\-permission-mode " " \fIask|yolo|plan\fR
Permission mode. Default: ask.
.TP
.BR \-\-workspace " " \fIpath\fR

.TP
.BR \-\-audit-log " " \fIpath\fR

.TP
.BR \-\-resume " " \fIid\fR
Resume a session by ID.

.BR \-\-branch " " \fIid\fR

.TP
.BR \-\-headless-output " " \fIjson|text\fR
Output format for headless mode (\fB-p\fR). Default: text.
.TP
.BR \-\-timeout-ms " " \fIn\fR
Max run time in ms. Default: 600000 (10 min).
.TP
.BR \-\-no-telemetry
Disable all outbound calls except the LLM provider.
.TP
.BR \-\-no-sandbox
Disable the kernel sandbox. \fBDev only\fR \(em prints a warning.
.TP
.BR \-\-screen-reader
Enable screen-reader mode (flattened TUI).
.TP
.BR \-\-debug
Enable trace logging + Node inspector.

Use the local-LLMs router (PII gating + complexity routing).
